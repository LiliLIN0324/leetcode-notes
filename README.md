| [力扣100题.ipynb](力扣100题.ipynb) | Hot 100 逐题：题干 + `class Solution` + 中文思路，从「两数之和」开始 |

## 怎么用

```bash
git clone https://github.com/LiliLIN0324/leetcode-notes.git
jupyter notebook
```

按顺序读任何一个 notebook 即可，代码单元格可直接运行（只用标准库，无第三方依赖）。
